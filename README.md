# AL STUDIO TOOLS DEV

Starter project for AL DEV TOOLS by AL STUDIO.

## Local run
1. Install Node.js.
2. Run `npm install`.
3. Run `npm start`.
4. Open http://localhost:3000

## Deploy
Import this NEW repository into your hosting provider.

## Current starter features
- Responsive dark RGB dashboard with top navbar
- Asset Manager (browser LocalStorage)
- Basic Luau indentation formatter (not a full parser)
- Robux fee simulator (editable assumption)
- Bug Tracker (browser LocalStorage)
- Dev Workspace project list (browser LocalStorage)
- About AL STUDIO

No changes are made to the existing `AL-STUDIO-UPLOAD-ID` repository.

## Notes
LocalStorage data stays in the current browser/device. Account login and cross-device sync are not implemented yet. Roblox Open Cloud integrations should be added server-side with secrets stored in environment variables, never in frontend code.
